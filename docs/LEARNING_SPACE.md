# 学习空间使用说明

> 学生端「办事 + 学习」双空间。  
> 学习数据目录：`learning_data/`（独立于 `data/`，`START_DEMO` 不会删除）。

---

## 1. 入口与页面

学生登录后，左侧导航出现「学习空间」，包含五个 tab：

1. **专注**：番茄循环（专注/短休/长休）、暂停继续、跳过、轮次、自动下一段、提示音、任务快捷开始；
2. **考试周**：考试倒计时、错题驱动的每日复习任务、生成/重排、直接进入专注；
3. **任务清单**：自然语言拆解、优先级、起止日期、提醒、完成勾选；
4. **复习**：按间隔重复排队的今日错题；
5. **报告**：最近 7 天专注、任务、复习、知识点分布；
6. **错题本**：建库、上传题目图片/文字、隐藏答案练习、提交批改、Teach-back；
7. **日历 / 课程**：公历月视图、任务、周末/示例节假日、课程表。

管理员也能看到学习空间，便于演示。

---

## 2. 专注

- 25/45/60 分钟；从任务点播放键会自动带出该任务的预计时长；
- 服务端记录 `started_at / planned_min / actual_min`；
- 结束时比较计划与实际，返回一句反馈；
- 深夜 23:00 后 / 凌晨 4:00–6:00 有不同提示；
- 今日累计来自已完成记录。

> 不检测“是否碰手机”，不做虚假的心流诊断。

## 3. 任务清单

输入示例：

```text
嗯，那个，今天复习高数2小时，重点看极限，背单词30分钟，明天交英语作业
```

支持两种模式：

1. **本地规则（默认）**：不消耗 Key；
   - 逗号、顿号、分号、换行、然后/接着/最后等连接词作为边界；
   - 无标点长列表按任务名词兜底切分；
   - 分句开头/结尾的语气词、重复连接词先清洗；
   - “重点看…”“明天交…”这类补充说明并入上一条；
   - 时长、优先级、起止日期、提醒仍可逐项修改。
2. **用模型提炼**：打开开关后调用学生已配置且测试通过的模型，按语义提取更清晰的任务；没有 Key 时会明确报错，不静默假装成功。

导入前可逐条修改；导入后清单里的每条任务都有删除按钮，误识别可以删掉。  
逾期或今日截止的待办会自动显示为高优先级。

## 4. 错题本

```text
新建「高等数学上错题本」
 → 上传题目图片，或粘贴题干
 → 本地预处理：去 EXIF、转 RGB、缩放到 1600px、保存
 → 调用“这个学生自己的”视觉模型
 → 保存题目（答案不下发）
 → 练习：题目图 + 题干 + 作答区
 → 提交：真实模型批改、步骤反馈、参考解析、知识点
```

### 删除与回收站

- 错题卡片右侧「删除」会二次确认；
- 错题本卡片右侧也可以删除整个错题本；
- **两个回收站分开**：
  - 「题目回收站」只放单道错题；
  - 「错题本回收站」只放整个错题本；
- 两者都保留 7 天，期间可以「恢复」或「彻底删除」；
- 7 天后访问对应回收站时自动清理过期项；
- 回收站里的内容不会出现在错题本、复习队列和学习报告计数里。

### 识别设置

上传区齿轮可调每次图片识别的参数：

- 2048 节省；
- 4096 较快（简单题/节省额度）；
- 8192 复杂（多步解析/公式较多的题）；
- 16384 常用（大多数题目推荐）；
- 32768 极大（慎重）；
- 超时 15–600 秒可调，默认 120 秒；
- 支持自定义和快捷下拉；
- 每次上传独立，不是累计额度。

上传后会显示识别进度条、当前阶段、已等待时间和本次超时上限。由于模型接口不提供真实 token 进度，进度是按等待时间估算的，不代表精确完成比例；最终以成功/失败结果为准。

### 查看解析

每道错题的「查看解析」会打开独立抽屉：

- 参考答案；
- Markdown 小标题、列表、代码；
- 分式、根号、上下标、希腊字母；
- \\ce{} 化学式；
- 不做 HTML 直出，先转义再排版。

### 关键变化：没有 mock

- 每个学生必须自己配置 API Key；
- 未配置 Key 时，上传题目直接提示“先配置”，**不会返回示例题**；
- 识别和批改都调用真实模型；
- 没有 Key 的学生无法使用拍照识别，但可以正常使用专注、任务和日历。

### 在哪里配置

学习空间右上角 → **模型设置**。这里是 **多配置档案**，类似 CC Switch：

```text
DeepSeek 高数模型   [当前启用] [已连通] [测试] [删除]
Qwen 题图增强       [切换]     [待测试] [测试] [删除]
+ 新增配置
```

新增配置：

- 选供应商预设：DeepSeek / Qwen-VL / 自定义；
- 预设自动填模型、Base URL、官网；
- 填 API Key；
- 可选填配置名称、备注/用途；
- 官网链接可点；
- 「保存配置」→「测试连接」→「设为当前」。

只有 **测试通过** 的配置才能设为当前；当前配置才用于拍题识别和批改。

**每个学生保存自己的配置**，互不可见。  
Key 只提交到服务端，使用 Windows DPAPI（当前 Windows 用户绑定）加密后存入 `learning_data/learning.db`；接口只返回 `sk-****1234` 掩码和指纹，不返回明文。

### 连接方式与路由

这里 **没有“路由开关”**。连接方式固定为：

```text
学生浏览器 → 知行后端（固定代理）→ DeepSeek/Qwen
```

原因：

- Key 只在服务端解密，不能下发浏览器；
- 图片需要先本地预处理；
- 后端要做审计、限流和错误处理；
- 学生不需要理解本地代理/端口/重启。

CC Switch 的路由开关是为桌面 CLI 工具切换供应商设计的；我们是 Web 服务，后端本身就是网关，给学生开关只会增加误配置和 Key 泄露风险。

### 与 CC Switch 的字段对应

| CC Switch | 我们的配置 | 说明 |
|---|---|---|
| 供应商 | 供应商预设 | DeepSeek / Qwen / 自定义 |
| 官网链接 | 官网链接 | 仅辅助，不参与请求 |
| API Key | API Key | 只写一次、加密、不可读 |
| 备注 | 备注/用途 | 如“高数拍题”“物理题” |
| — | 配置名称 | 多配置时区分 |
| — | 模型 ID / Base URL | 预设自动填，自定义可改 |
| — | 测试状态 / 最近测试 | 测试通过才能设为当前 |
| 路由开关 | **不提供** | 后端固定代理，避免 Key 下发和误配置 |

**只写一次规则：**

- 保存后没有任何接口可以取回明文；
- 不能覆盖，必须点「删除 Key 并重新录入」；
- 服务端只在调用模型的内存中解密；
- 严格单向哈希不能用来调用模型，所以这是“接口不可读 + 加密存储”，不是“服务器永远无法解密”。拥有服务器/Windows 账户权限的人理论上仍可解密；生产应换 KMS/HSM。

DeepSeek 示例（当前官方支持图片输入）：

```text
Base URL: https://api.deepseek.com
模型: deepseek-flash
```

旧的 `deepseek-v4-flash-vision-exp` 已下线，但请求会由最新 Flash 承接；不要填 `deepseek-v4.1-flash`，用 `deepseek-flash`。

Qwen 也可以：

```text
Base URL: https://dashscope.aliyuncs.com/compatible-mode/v1
模型: qwen-vl-max
```

豆包/智谱/OpenAI 的 Base URL 和模型名不同，按厂商文档填。

### 服务端环境变量方式（可选）

如果不想在页面填，也可以让服务端统一配置，但当前实现优先使用学生自己的加密配置：

```env
CAMPUS_LEARNING_VISION_BASE_URL=https://api.deepseek.com
CAMPUS_LEARNING_VISION_MODEL=deepseek-flash
```

### 图片处理（混合模式）

- 原图只在校内服务器；
- 本地去 EXIF、缩放、保存；
- 真实模型返回归一化 `question_bbox` 后，后端裁出题图；
- 当前只发送预处理后的图片/题图给模型，不做本地 OCR、不做自动人脸/姓名打码；
- 严格“图片不出校”需要私有化模型，见 `LEARNING_IMAGE_PRIVACY.md`。

## 5. 间隔重复

提交错题批改后自动安排下次复习：

- 答对：连对 1 次 → 3 天后；2 次 → 7 天；3 次 → 14 天；之后 30 天；
- 部分正确：明天；
- 答错：连对清零，明天再来。

「复习」tab 只显示今天到期的题；练习完成后更新到期日。

当前是固定间隔，不是 SM-2/FSRS；好处是透明、可解释，后续可替换算法。

## 6. 课程资料

课程表里每门课有「资料」按钮：

- 粘贴课件文字、笔记、知识点，或上传 Word/PDF/TXT/MD；
- 资料按课程隔离，只给当前学生；
- 课程内用 TF-IDF 检索，返回标题 + 片段 + 分数；
- 不调用大模型，也不做跨课程混合检索。

## 7. 作业提取

任务清单里点「从作业图片/文字导入」：

- 上传作业截图，或粘贴作业通知；
- 调用学生自己的视觉模型提取标题、课程、截止日、要求；
- 提取结果可改；
- 确认后导入任务清单。

没有配置/测试模型时直接拒绝，不返回假作业。

## 8. 日历 / 课程

- 月视图，周一开头；周末标色；
- **顶部双模式切换**：
  - 课程表：按星期显示每周课程，包含时间、课程名、地点；
  - 待办任务：按截止日期显示任务，无日期任务不显示；
- **周视图 / 月视图**切换；周视图一周一屏，可设置周一或周日开始；
- **学期开始日期**用于计算第几周；课程可填周次（如 `1-16`、`5,10-17`）和单双周；
- 日历占满整行，格子加高，单格最多显示 3 条，更多显示“+N 更多”；
- 显示设置：周末、时间、网格、格子高度、圆角、不透明度、文字色、边框色；
- 2026 法定节假日为示例数据，正式版接校历；
- 课程表支持手动添加课程、时间、地点、本周作业；
- 支持粘贴文本导入，例如：

```text
周一 08:00-09:40 高等数学 A101
周二 13:30-15:10 大学物理 B203
```

## 10. 当前边界

- **计划拆解**默认是本地规则；可在任务区打开「用模型提炼」走学生模型；
- 无标点/口语长列表只能做规则兜底，不保证完全正确；
- **视觉识别/批改**已去掉 mock，必须配置学生自己的 Key；
- `deepseek-flash` 是推理型模型，图片识别默认 16384 tokens；读取超时 120 秒；复杂图可在上传区调高，过高更慢更贵；
- 识别 token 上限保存在浏览器 localStorage，换设备回到 16384；
- 解析排版是本地轻量 Markdown/公式层，支持分式/根号/上下标/化学式，但不是完整 KaTeX，矩阵/复杂对齐不支持；
- 解析字体首选 **TeX Gyre Termes Math**；本机未安装时回退 Times New Roman / Latin Modern Math。可把 `texgyretermes-math.otf` 放到 `static/fonts/`；
- 题目和错题本各有一个 7 天回收站，访问回收站时才清理过期项；
- **提醒**目前是页面内轮询提示，不是企业微信/短信推送；
- **课程表**支持周次/单双周过滤，但还没有课程编辑入口，也没有整张课表图片解析；
- **假期**是 2026 示例，不是校历；
- 图片严格不出校需要私有化模型，当前混合模式只做到“预处理后上云”。
