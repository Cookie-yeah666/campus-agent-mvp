# 安全与隐私边界

> 课程原型的安全基线；不是生产等保方案。

## 1. 身份与权限

- 工作人员：HMAC-SHA256 自包含 Token，默认 8 小时；
- 学生：学号 + 姓名 + 学号后六位，姓名必须与 `registry/students.db` 一致；
- 角色：student / counselor / auditor / admin；
- 会话、工单、审计、学生库都按角色和学院过滤；
- 学生只能看自己；辅导员本学院；审计员/管理员全量（审计员只读）。

## 2. 密码与 Key

### 工作人员

- PBKDF2-HMAC-SHA256，12 万次迭代，随机盐；
- 只用于本地演示。

### 学生密码

- 初值为学号后六位；
- 未单独存密码哈希；
- 生产必须接 CAS/OAuth2 并强制改密。

### 学习 API Key

- 每个学生独立配置；
- 保存后接口只返回 `sk-****1234` 和 SHA-256 指纹；
- 不能查看、不能覆盖，只能删除后重新录入；
- 数据库存 Windows DPAPI 密文，不存明文；
- 服务端只在调用模型的内存中解密；
- 严格单向哈希不能用于调用模型，因此这不是“服务器永远无法解密”；
- 生产应使用 KMS/HSM/专用密钥服务。

### 图片

- B 混合模式：本地去 EXIF、缩放、保存；
- 真实模型返回 bbox 时裁题图；
- 预处理图会发给云模型，**不是图片不出校**；
- 严格不出校需要校内私有化模型。

## 3. 审计

- JSONL 记录消息、意图、检索、工具、节点、确认、幂等、转人工、登录、评测；
- 工单保存流程定义版本与快照；
- 审计日志带 `prev_hash + hash` 哈希链；
- `GET /api/v1/audit/verify` 可由审计员/管理员校验，发现 prev/hash 不一致会返回断点；
- 旧的无 hash 日志计入 `legacy`，不伪装成已链化；
- 生产仍应加只追加存储、外部锚定和访问审计。

## 4. 权限感知

- 学生库手机号默认脱敏；
- 学习通知只给 owner；
- 学习模型配置只给 owner；
- 人工坐席按会话可见性过滤；
- 审批队列按学院/角色过滤。

## 5. 仍需补的安全项

- Prompt 注入已加拦截与回归测试，仍需持续红队；
- 权限感知检索（不同角色检索范围不同）；
- 审计哈希链已实现，仍需外部锚定/只追加存储；
- 登录限流、验证码、异常登录告警；
- 上传文件病毒扫描、图片压缩炸弹防护；
- 外部通知渠道的隐私审查；
- 数据保留/删除策略；
- 生产 KMS/HSM。

## 6. 演示数据边界

- `registry/students.db` 是真实名册，不提交、不外传；
- `learning_data/` 含学生任务/错题/Key 密文，不提交；
- `data/` 是可重置演示数据；
- 演示时不要用真实学生作业照片测试公有云模型。
