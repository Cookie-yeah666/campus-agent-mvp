# 错题本排版字体

按传统数学试卷规范：

- 中文正文：Noto Serif SC → 宋体 / SimSun；
- 西文正文：Times New Roman；
- 公式：STIX Two Math → Times New Roman → Cambria Math。

## 可选字体文件

本目录也保留了：

- `texgyretermes-math.otf` / `texgyretermes-regular.otf`
- `latinmodern-math.otf`

它们不是当前首选，但已经在 CSS 的候选栈里，安装或保留文件不会破坏排版。
