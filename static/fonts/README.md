# 错题本排版字体

错题本优先使用 **TeX Gyre Termes Math**，回退顺序为：

1. TeX Gyre Termes Math
2. TeX Gyre Termes
3. Latin Modern Math
4. Cambria Math / Times New Roman

## 启用 TeX Gyre Termes Math

把 `texgyretermes-math.otf` 放到本目录，刷新页面即可。
字体来源：CTAN `fonts/tex-gyre`（`texgyretermes-math.otf`）。

## 启用 Latin Modern Math

也可以把 `latinmodern-math.otf` 放到本目录，作为回退。

如果系统已经安装同名字体，浏览器会优先使用本机字体，不需要复制文件。
字体授权请以发行包内的 GUST Font License / 字体说明为准。
